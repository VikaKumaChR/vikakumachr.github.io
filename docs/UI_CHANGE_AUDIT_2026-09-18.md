## 同日後續修正

上表記錄上一輪處理；收到新的三張截圖後，下列決策已被取代：

- 移除「等圖示播放 240ms 才跳轉」的等待。圖示與捲動同時開始；每次點擊都重新定位，不依賴 hash 值是否改變。
- 頁首改用實際的 Fluent React TabList／Tab，保留官方底線位移動畫。手機外層 overflow-x 改為 clip，修正 sticky 頁首失效及落點計算錯誤。
- 移除額外繪製的直線菱格，保留提供的蕾絲圖；手機由單向漸層改為雙軸橢圓遮罩，柔化素材邊緣。
- 官網入口實測為無邊框的 shadow4、22px 圓角。移除入口額外邊框；札記及須知移除手動外觀覆寫，交由 Card 預設 filled 外觀處理陰影與明暗變化。

實際檢查包含連續動畫影格、重複點擊同一目標、快速改選、鍵盤、上一頁／下一頁、直接帶 hash 開啟、五種視窗寬度與瀏覽器觸控模擬。最新決策與來源見 UI_LAYOUT.md。
