# Layout and interaction decisions

Reference: https://fluent2.microsoft.design/layout (read in full, 2026-09-17).
Visual reference: https://fluent2.microsoft.design/ (opened in a browser and measured, 2026-09-18). Its homepage entry cards measure 152px high with 32px padding and a light shadow at the inspected desktop width.

- **Spacing and proximity:** 4px spacing ramp; 16px within small groups, 24px content card padding, 32px between headings and content, 48px desktop columns, 64px desktop sections. Homepage entry links retain full 152px cards with 32px padding, 22px corners and a light, static shadow, as measured on the reference homepage. Hover never translates or scales these cards.
- **Grid:** restore the published site's separate edges: header, external links and footer use `clamp(18px, 4vw, 54px)` side gutters. The hero is capped at 1240px and article/gallery content at 1280px. The lower notice card is 360px wide on desktop and stacks on mobile. Do not align the site chrome to the article column.
- **Alignment:** section headings, descriptions and link text share consistent edges; icons are centered within their boxes. Functional icons use 24px SVG canvases and at least 44px interaction targets.
- **Responsive design:** the character and introduction stack below 1024px. The header becomes sticky and navigation moves to a second row. The shell uses `overflow-x: clip`; `hidden` created a non-scrolling ancestor that broke the mobile sticky header. Smaller viewports remove excess hero minimum height. Content reflows without horizontal overflow.
- **Responsive techniques:** resize artwork independently from the viewport; reposition/reflow the hero and lower sections; hide the brand subtitle only on small screens. Existing content remains accessible. No additional disclosure UI is needed.
- **Character frame:** the lace circle is anchored to the character center. Desktop texture width is 2.35 times the character height; the visible circle diameter is about 89% of that height. The page-wide pattern is separate, so ultrawide screens cannot enlarge the circle. Entry cards overlap the figure's bottom by 24px on desktop and 16px on mobile, hiding the cropped edge and grounding the portrait. No floating animation is used.
- **Background:** remove the separately drawn diagonal grid. Keep the supplied lace/argyle image over pale lavender and blue gradients. Feather its edges with an elliptical mask in both axes; the old mobile vertical-only mask left a visible horizontal lace strip. Image positioning remains anchored to the character; no source image was rewritten.
- **Header navigation:** retain Fluent React `TabList`/`Tab` for selection and keyboard behavior, but replace their per-tab sliding indicators with one persistent `NavigationIndicator`. The user requested WinUI's stretch/contract motion, which React Tab's simple translation does not reproduce. Follow `NavigationView::PlayIndicatorAnimations` in Microsoft commit `b806c885762ea4a1b14bb996c20b0510b8d2f459`: first 200ms stretch toward the destination with `curveAccelerateMax`, then 400ms contract the trailing edge with `curveDecelerateMax`. This explicitly requested reference overrides the animation skill's generic under-300ms recommendation. Clip one surface to keep round ends, no opacity fade; reverse from the currently painted shape on interruption. Suppress the extra hover line, snap on resize and reduced motion. All section navigation uses the measured header height plus 16px. Repeated clicks scroll even if the hash is unchanged, rapid clicks retarget immediately, and scroll tracking resumes after scrolling settles or the visitor intervenes.
- **Theme control:** retain the measured 30×18px transparent track, 2px outline, 9px thumb and 12px travel, before Share and Language. The user's explicit circle-to-crescent request overrides the reference homepage's plain dot. An SVG mask morphs the thumb without swapping icon families or stroke weights. Native View Transitions reveal complete palettes over 240ms; do not interpolate inherited text colors or cross-fade inverse text/background colors. The live switch animates separately during the reveal. Reduced-motion and unsupported browsers apply the palette immediately. Rapid changes cancel the previous reveal and retain the latest choice.
- **Entry icons:** the reference homepage's illustrative icons occupy 90px canvases. These line icons use 80px desktop and 56px mobile canvases. PhotoCollection and Library animate their individual photos/books for 240ms on activation while scrolling starts immediately in the same handler. Never await icon feedback before navigation. Modified clicks keep native link behavior; repeated activation follows the latest target. Hover never triggers motion. Reduced-motion navigates immediately. This is a web SVG implementation of interaction-triggered animated icons, not the Windows-only WinUI AnimatedIcon control.
- **Gallery:** use Fluent's actual `CarouselNavContainer`, `CarouselNav`, `CarouselNavButton` and arrows, on the right of the caption. Override the navigation container's default alpha background to transparent in both themes; use the brand appearance for the active indicator. Preserve the official 8px dots and 16px selected indicator. The public `CarouselProvider` connects navigation to the existing expanding-image layout. One selected index drives cards, caption, selected tab and panel label. Arrows, dot/card clicks, keyboard arrows, horizontal wheel gestures and pointer swipes all use the same navigation function. Direction is explicit at wrap boundaries. FLIP animates previous and next oppositely; vertical touch scrolling remains native. Reference: https://fluent2.microsoft.design/components/web/react/core/carousel/usage/#image-gallery-layout.
- **Card elevation:** the reference homepage uses `0 0 2px rgba(0,0,0,.12), 0 2px 4px rgba(0,0,0,.14)` with no visible border, matching Fluent light `shadow4`. Entry links use that theme token without an added border. Notes and the notice use the actual `Card` default filled appearance, removing hand-added border/shadow/background overrides. Theme tokens supply the dark shadow. Reference: https://stackblitz.com/edit/cqwif7?file=src%2Fexample.tsx (read the full source), https://fluent2.microsoft.design/components/web/react/core/card/usage, and https://fluent2.microsoft.design/elevation.
- **Notes:** preserve all three read buttons. Hover never lifts a card. Brand buttons use `colorNeutralForegroundOnBrand` with a dark foreground on the light lavender fill in both themes, including hover/pressed states. A click shows a brief Fluent Toast for unpublished content. Feedback and toolbar tooltips use Noto Sans; editorial text keeps Noto Serif.
- **Localization:** the notice card is 須知 in zh-TW and 须知 in zh-CN. Creator handles remain unchanged.
